# Confederate States Civilization Mod for UnCiv

A mod that adds the Confederate States as a playable civilization in UnCiv with historically-inspired unique units, buildings, and game mechanics.

## Features

### Civilization Bonuses
- **Home Defense & Cotton Trade**
  - +15% Strength when fighting in Friendly territory
  - +1 Gold from Plantation tiles

### Unique Units
- **Foot Cavalry** (replaces Rifleman) - Mobile melee unit with terrain bonuses
- **Stuart's Cavalry** (replaces Cavalry) - Fast cavalry with post-attack movement
- **Cherokee Rifles** (replaces Gatling Gun) - Ranged unit with forest camouflage
- **Blockade Runner** (replaces Privateer) - Naval raider with enhanced economics
- **CSS Virginia** (replaces Ironclad) - Powerful armored warship
- **CSS Alabama** (replaces Frigate) - Naval commerce raider
- **CSS Shenandoah** (replaces Frigate) - Arctic-capable naval unit
- **Conscript Militia** (replaces Worker) - Can trigger rebellion events when unhappy
- **Confederate General** (replaces Great General) - Strong military leader unit

### Unique Buildings
- **Supply Depot** (replaces Armory) - Boosts gunpowder unit production
- **Blockade Runner Port** (replaces Harbor) - Enhanced trade and gold generation
- **State Arsenal** (replaces Military Academy) - Superior military unit training

### Special Events
- **Rebellion** - Triggered when Conscript Militia units operate in unhappy cities

## Installation

1. Download or clone this repository
2. Copy the mod folder to your UnCiv mods directory:
   - **Android/PC**: `UnCiv/mods/`
   - **iOS**: Through the in-game mod manager
3. Launch UnCiv and enable the mod in the mod menu

## Gameplay Balance

This mod is balanced for standard difficulty. The Confederate States excel at:
- Defensive warfare (home territory bonuses)
- Naval commerce and raiding
- Economic bonuses from plantations and trade
- Military production and experience gains
